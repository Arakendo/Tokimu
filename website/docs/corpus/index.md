# Executable evidence

Tokimu's corpus is not a gallery of disposable samples. Each entry exists to
test a claim, retain observations, and expose the first boundary that fails.

## Current external corpus families

The repository currently carries or plans bounded evidence for:

- W3C SVG fixtures;
- glTF and GLB sample assets;
- CGM fixtures;
- FBX fixtures;
- font outlines and glyph providers.

Coverage is meaningful only with a declared profile and denominator. The first
published records are:

- the [W3C SVG evidence page](../formats/svg.md), whose upstream coverage
  values are checked against the authoritative SVG library record; and
- the [CGM evidence page](../formats/cgm.md), whose bounded selection and stage
  counts are checked against the authoritative CGM library record.

Stale claims fail website validation rather than silently surviving a corpus
change.

## Structural evidence first

For presentation geometry, structural artifacts identify where a transformation
first diverges:

```text
source
  → parsed document
  → semantic observation
  → vector or mesh representation
  → renderer submission
  → visual evidence
```

Screenshots are useful, especially for human and AI inspection, but pixels do
not replace structural assertions.
