# ASP.NET WASM Presentation Workbench

This consumer corpus entry proves that an ASP.NET-hosted TypeScript application
can select provider-neutral vector and mesh targets, author bounded material
presentation intent, and have Rust/WASM resolve that intent without putting
shader, renderer, or imported-source semantics in the browser.

```powershell
npm install
pwsh -NoProfile -File .\build.ps1
dotnet run
```

The first proof intentionally uses a fixed scene. It does not parse assets,
compile browser shader code, or claim a production WebGPU renderer.
