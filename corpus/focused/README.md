# Focused Corpus

Focused proofs answer one bounded architectural question without belonging to a
sustained campaign.

| Domain | Scope |
| --- | --- |
| [Foundations](foundations/README.md) | windows, basic rendering, shaders, stereo/XR, and vector drawing |
| [Simulation](simulation/README.md) | rules, physics, application workloads, particles, FPS, and CAD |
| [Observation](observation/README.md) | runtime observation, terminal surfaces, shells, and workbenches |
| [Data Interchange](data-interchange/README.md) | import/export, files, resource space, images, compression, and archives |
| [Audio](audio/README.md) | analysis, visualization, and music visualization |
| [Networking](networking/README.md) | loopback and client/server seams |

If a focused proof grows into a sustained work campaign, move it under
`corpus/campaigns/` and create the corresponding `docs/Plans/` portfolio. Do not
duplicate its shared implementation; keep that under `corpus/lib/`.
