# Option B Representative Migration And Conversion Evidence

Date: 2026-08-12

## Scope

This is Slice 5 evidence for the separate Narrow B and Full B candidates. It
does not migrate production, select a candidate, promise wrapper layout, or
claim that a checked corpus branch is a stable Tokimu API.

The same application-shaped controls cover stereo and mono cameras,
orthographic Asteroids presentation, CAD projection and picking, the E1M1
PreserveNorth observer, FPS movement, GLB point/normal transforms,
hole-punch hierarchy mutation, renderer camera transport, and the AR-0026
chart transition/orientation control. Doom collision is an explicit
non-applicable item: the retained collision implementation operates on source
integer/scalar records and does not consume the Native `glam` vocabulary.
Inventing a wrapper crossing for it would manufacture pressure.

## Narrow B Result

The isolated Narrow-B harness retains `glam` values while replacing only the
three semantic construction families. One unchanged caller source passes
against exact 0.29.3 and 0.33.3 and now contains four contract tests plus four
representative tests.

| Caller pressure | Public Narrow-B seam | Result |
| --- | --- | --- |
| Stereo | one perspective and two view constructions | distinct finite eye matrices |
| E1M1 observer | one view construction | source eye maps to view origin |
| CAD/picking | one view and one perspective construction | finite normalized ray |
| Renderer transport | one perspective construction plus scalar columns | exact scalar round trip |
| Asteroids/storage | one orthographic construction retained in stored camera state | expected clip coordinates |

Accounting for this bounded port:

- representative source modules edited: **1** isolated external-caller module;
- caller scenarios represented: **5**;
- changed public value signatures: **0**;
- accessor/setter substitutions: **0**; provider fields and traits remain A's
  public vocabulary;
- explicit value conversions or temporary allocations: **0**;
- semantic-construction calls crossing the private adapter: **8**;
- provider API adaptations visible to callers: **0**; the 0.29/0.33
  constructor difference remains in three private adapter functions.

Narrow B therefore contains the update shock that actually occurred in Option
A, but it does **not** insulate `Vec3`, `Vec4`, `Mat4`, traits, fields, layout,
or ordinary operations from a future provider change.

## Full B Result

Full B is exercised in nine A/B/C-comparable caller modules: the eight retained
`migration_hello_*` modules plus `chart_junction`. `migration_b` is the tenth
candidate-specific adapter module. These are corpus ports; stable Tokimu source
edits remain zero.

| Count | Full B observation |
| ---: | --- |
| 9 | representative caller modules with A/B/C branches |
| 4 | private helper signatures changed to wrapper values |
| 8 | scalar component accessor substitutions |
| 1 | explicit matrix-column setter substitution |
| 9 | renderer matrix crossings in the retained camera/upload set |
| 0 | provider types in candidate-facing public signatures |
| 0 | required trait losses in the retained caller set |
| 0 | allocations in 100,000 transform and upload controls and 10,000 stereo controls |

The four wrapper-bearing helper signatures are two stereo helpers, the FPS
snapshot helper, and the CAD homogeneous-ray helper. The eight component
accesses are the FPS X/Z reconstruction and CAD homogeneous-W checks/divides.
The one setter is the hole-punch hierarchy's final matrix column. Missing broad
traits, indexing, swizzles, public fields, POD/FFI, and serialization remain
deliberate non-contracts; no retained caller required them.

The AR-0026 control now executes A, Full B, and C0 over identical authored chart
meaning. All produce fingerprint `2520c9de`, preserve the composed transition,
classify the reflection as reversing, and restore the original point. Full B
needed no new ordinary operation. Explicit unit vectors avoided growing X/Z
constants merely to make the fixture look provider-like.

## Crossing Classification

| Crossing or friction | Classification | Reason |

No crossing uses `transmute`, pointer casts, unchecked layout equivalence, or a
wrapper/provider reference reinterpretation. Equal observed size/alignment is
retained elsewhere only as an observation.

## Validation

  the chart control; the focused Full-B public-boundary suite passed 2/2.
- Native chart observer: A, B, and C0 produced fingerprint `2520c9de`.

- Narrow B: 4 contract + 4 representative tests pass unchanged against exact
  0.29.3 and 0.33.3.
- Allocation controls: transforms `100000` = A/B/C `0/0/0`; uploads `100000`
  = B/C `0/0`; stereo `10000` = A/B/C `0/0/0`.
- Production 0.29.3 still emits its known generated-source warning flood;
  warning suppression used for readable focused runs does not reclassify it.

## Finding

Narrow B is proportionate to the demonstrated Option-A semantic-constructor
shock and imposes very little caller churn. Full B is feasible across broad and
per-frame callers, but it buys a much larger owned vocabulary and recurring
wrapper surface to contain changes that have not yet occurred. Slice 5 adds no
evidence that Full B is required in order to own the camera/projection meaning.
