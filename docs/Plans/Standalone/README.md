# Standalone Plans

These plans do not currently belong to a sustained work campaign. Their
location is explicit triage, not an archive and not a statement that they are
inactive.

Promote a standalone plan into a named campaign when it gains a controlling
checklist plus related studies or evidence. The new campaign README must state
its current status, controlling document, next action, and reopening triggers.
